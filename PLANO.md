# Plano de etapas

Cada etapa termina com algo **usável no celular** e publicado.

| # | Etapa | O que dá para fazer ao final |
|---|---|---|
| 1 ✅ | **Catálogo** — categorias e produtos (entidades, regras, telas, + Produto) com os 74 produtos da planilha já carregados | Ver e cadastrar produtos no celular |
| 2 ✅ | **Montar a lista** — compra planejada, itens, quantidades − / +, previsto, R1/R2 | Montar a lista de casa |
| 3 | **No mercado** — marcar comprado, preço, indisponível, real × previsto, item esquecido, encerrar/cancelar | Fazer a compra inteira pelo app (offline) |
| 4 | **Histórico e preços** — tela de histórico, variação de preço (D3), repetir última compra (D4) | Consultar compras e montar lista num toque |
| 5 | **Planilha do Google** — backend (clasp), sincronização, importação dos dados | Backup e uso em outro aparelho |
| 6 | **Publicação** — GitHub Pages + instalar no celular | App na tela inicial |

Obs.: a publicação no GitHub pode ser feita já depois da etapa 1, para testar no celular de verdade
desde o começo.
